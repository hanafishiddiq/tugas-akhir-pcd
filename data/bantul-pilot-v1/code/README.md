# Helper data pilot Bantul

Helper menjalankan pemeriksaan dataset dan keluaran pipeline tanpa melatih atau menjalankan model. Paket Bantul 222 dibaca hanya sebagai referensi. Helper tidak melatih model. Pembagian paket ini sudah dikunci pada ../SPLIT_LOCK.json setelah pemeriksaan mandiri.

## Uji dan pemeriksaan kesiapan

Dari root proyek, gunakan environment Tahap 03 yang sudah tersedia.

```sh
PY=Jawaban/Perencanaan_Baseline/Tahap_03/kode/.venv/bin/python
D=Data/Eksperimen/Bantul_Pilot_v1/code
"$PY" -B "$D/run_tests.py"
"$PY" -B "$D/readiness.py" --root "$PWD" --paths /path/ke/INPUT_PATHS.json
```

Bila helper dipindahkan, set BANTUL_PROJECT_ROOT ke direktori proyek atau BANTUL_REFERENCE_CORE ke file core.py sumber. Helper juga dapat memakai reference_core.py yang dibundel di sebelahnya dan mengikat hash file yang benar-benar dipakai. Fixture asli memerlukan project root.

Tes memakai kasus sintetis dan lima fixture beku B008, B049, S033, S034, W072 dari paket 222. Fixture mengecek sumber/hash audit dan hasil adapter terhadap acuan paket. Evaluasi prediksi hanya diuji dengan prediksi sintetis. Receipt mengikat hash kode, fixture dan modul anotasi asli. Validator keluar dengan kode 1 bila gate gagal dan melaporkan setiap ambang yang belum terpenuhi. Gunakan api write_split_lock hanya setelah peninjauan final. Ia menghitung ulang gate dan hash aset, membandingkan hash input yang sudah ditinjau lalu membuka target dalam mode eksklusif.

### Input validator

INPUT_PATHS.json memetakan key manifest, annotations, rois, groups, protocol, test_receipt ke file di root pemeriksaan. Key auxiliary_manifest opsional. Berkas di luar root perlu deklarasi documented_external_assets di protocol, dengan resolved_path dan sha256. File input utama sendiri harus tetap dalam root. Bukti absolut lama di dalam root tetap dapat diverifikasi tanpa mengubah record hash-bound.

- **manifest** berisi satu record per gambar core. Field wajib image_id, source_image, source_sha256, camera_id, width, height, roi_version, session_id, location_group, native_checked, roi_checked dan framing_evidence. Untuk pasangan batas dalam sesi, sertakan source_program_date_time dari sumber.
- **annotations** memakai format ANNOTATIONS.json Bantul 222 dengan cross_audit. Validator menghitung ulang hash raw reviewer, schema dan metrik acuan. Audit harus punya reviewer berbeda, bukti sumber serta overlay, status lolos dan daftar masalah terbuka kosong. Aset bukti perlu path yang dapat dibuka.
- **rois** adalah map kamera ke geometri dan hash mask yang terkunci, mengikuti ROIS.json. mask_path opsional jika memakai path standar Data/ROI/Bantul_v1/masks/<camera>_road.png. Untuk geometri tambahan, gunakan mask native yang sudah diaudit dengan path eksplisit. Mask harus biner dan luas piksel serta dimensinya cocok dengan record ROI.
- **groups** memuat images, must_link dan boundary_evidence. images memetakan setiap ID core dan auxiliary ke split, sample_role, component_id, event_ids, object_encounter_ids, full_count_encounter_id untuk core full-count (omit atau null untuk partial), serta source_time_utc yang harus cocok dengan HLS PDT bila disediakan. Exclusion split embargo atau quarantine memerlukan exclusion_reason. sample_role core queue_or_control atau auxiliary_moving, dengan moving train-only. Pemisahan gambar duplikat diuji lewat hash file dan RGB. object_encounter_ids memetakan setiap accepted object ke identitas/pertemuan konservatif. full_count_encounter_id mewakili satu pengamatan adegan independen walaupun ada beberapa kendaraan, sehingga dukungan full-count memerlukan keragaman adegan serta identitas. Kesamaan ID event, component, instance encounter atau scene encounter lintas split ditolak. Relasi must_link menyimpan image_ids dan path evidence. Pemeriksaan graf menelusuri relasi transitif melalui foto yang dikarantina. Jika sumber transit bukan bagian eksperimen, simpan link antara dua ID aktif beserta bukti yang menjelaskan jembatan tersebut.
- **boundary_evidence** memuat kind separate_acquisition_windows dengan path evidence, atau kind within_acquisition_reset dengan location_group, session_id, cut_utc berzona, embargo_each_side_seconds, subsets_before, subsets_after dan path evidence. Seluruh pasangan subset pada lokasi/sesi yang sama harus dipisahkan oleh batas berisi bukti. Jam dan margin yang diterapkan bersumber dari manifest. Helper memeriksa ikatan dan batas. Kebenaran visual penggantian antrean, near-duplicate, serta kecocokan ID kendaraan harus diaudit sebelum memasukkan bukti.
- **protocol** memuat evaluation_claim fixed_camera_temporal_holdout dan gates dengan nama dan nilai dasar sesuai readiness.MINIMUM. Validator menerima ambang yang lebih ketat. Perubahan di bawah kontrak ditolak.
- **auxiliary_manifest** hanya memuat crop classifier train-only yang sudah ditinjau. Record gambar memiliki semua AUX_RAW_KEYS, beserta annotation_sha256, cross_audit dan cross_audit_status. sample_role pada record dan groups.images harus auxiliary_classification_train_only. Setiap objek punya id yang diawali ID gambar dan tanda hubung, class_name empat kelas, bbox_xyxy integer native, confidence high dan reason yang dapat ditinjau. Reviewer dan auditor berbeda serta memakai hash dari canonical_hash atas seluruh AUX_RAW_KEYS. Crop mesti ditautkan ke vehicle encounter dan component yang dipakai untuk core bila sesuai bukti. Source PDT dan ukuran diperiksa. Peran ini tidak memerlukan ROI/full-count dan tidak menjadi sumber negatif. Kandidat manifest flat digabung per image_id oleh penyusun paket. Tidak ada copy atau crop JPEG yang dibuat oleh adapter.

Validator melaporkan dukungan core dan classifier_train_support terpisah. Dukungan train classifier menggabungkan accepted core dan crop auxiliary terverifikasi, menghitung crop RGB+koordinat identik sekali dan tetap menjaga encounter. Semua dukungan deteksi validation/test dan hitungan lengkap hanya berasal dari core. Syarat binary detector meliputi ketersediaan positif kendaraan core dan frame train antrean/kontrol lengkap yang memungkinkan pemeriksaan negatif. Kelayakan sebuah rectangle background tetap diperiksa saat kandidat diberikan. Rumus dan audit tidak membuktikan performa model.

## Bentuk API dan semantik

- dataset.adapt(record, mask) membaca partisi accepted, neutral, known_other dan daftar eksklusi. Cari metrik kelas opsional dari class_count_reference dan class_reference_mask. Pending target satu kelas membuat kelas itu tidak diketahui. Unknown dan ignore region relevan tanpa daftar kelas membuat keempat kelas tidak diketahui. possible_classes pada ignore region hanya dipakai bila ada possible_classes_reason visual yang terikat hash audit. Ini diagnostik tambahan. Acuan total, cakupan dan gate full-count tetap memakai kriteria lengkap.
- dataset.train_positives(record, mask, group) mengeluarkan bbox accepted dari core train. dataset.auxiliary_positive_manifest(record, group) membentuk metadata crop classifier, setelah readiness memverifikasi audit dan sumber. dataset.negative_manifest(record, mask, group, candidates) menyaring rectangle integer half-open yang seluruh pikselnya dalam mask jalan native. Padding 8 piksel dikenakan pada setiap objek atau ignore region, termasuk other/context/outside. Frame partial, auxiliary_moving dan val/test tidak menghasilkan negatif. Hash baris mengikat sumber, koordinat dan split.
- evaluate.evaluate_holdout(frames, masks_by_camera, groups_images, results, subset="test") menerima map hasil per ID gambar terpilih. Hasil valid berbentuk status ok dan daftar predictions dengan id unik, class_name, bbox_xyxy integer half-open, confidence berupa skor finite (margin SVM juga sah), serta roi_membership inside/outside/uncertain dari pipeline. Prediksi inside mengikuti urutan confidence menurun, dengan pembanding ID bila seri. Matching kelas yang cocok memakai IoU >=0,5 dan satu accepted GT per prediksi. Salah kelas atau duplikat dengan IoU yang cukup tetap FP, termasuk bila bertumpuk dengan ignore. Known other inside dan kendaraan yang dipastikan di luar pendekat sasaran tetap FP bila IoU >=0,5, setelah kesempatan matching accepted GT. Neutral berdasarkan luas union zona ignore dalam prediksi >=0,5 luas prediksi. Prediksi uncertain dilaporkan sebagai abstain dan tidak menghapus FN.
- Hitungan dan luas union dipotong mask ROI menggunakan daftar prediksi inside yang sama. Deteksi neutral tidak mengubah prediksi jumlah pipeline. MAE dihitung hanya pada frame acuan lengkap. Partial dilaporkan terpisah. Input gagal, hilang, duplikat, bbox invalid atau keluaran di luar subset membatalkan agregat run. Output memuat exposures keseluruhan, per kamera, per scope acuan, serta TP/FN per encounter positif. class_count_reference opsional tidak masuk MAE utama.
