# Dataset CCTV Bantul

Paket aktif untuk v45 adalah [Bantul Pilot v1](bantul-pilot-v1/README.md). Di sana tersedia anotasi empat kelas, ROI, pembagian data terkunci, dan petunjuk pemulihan. Foto serta overlay dapat dilihat di [folder dataset tim](https://drive.google.com/drive/folders/1dL_hXMOnOQvsBkwFW4IsZBJYo-ulJcR5).

Kami mengambil rekaman dari lima sudut CCTV, memilih 222 gambar, lalu memeriksa kotak kendaraan dan posisi tiap kendaraan terhadap area jalan. [Ringkasan pengambilan](bantul-20261115/acquisition_summary.json) · [Daftar 222 gambar pilihan](bantul-curated-v3/MANIFEST.csv) · [Aturan anotasi](bantul-annotations-v1/ANNOTATION_PROTOCOL.md) · [Hasil pemeriksaan anotasi](bantul-annotations-v1/SUMMARY.json).
